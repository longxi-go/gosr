# gosr tools v0.1.1

Update the package-loading and annotation adapters against gosr v0.1.2.
Requires Go 1.27.0 or later.

- Track marker definitions and repetition policy by target and marker name
  through a typed identity instead of concatenated strings.
- Retain source positions and parser causes when diagnosing unknown, misplaced
  or duplicate annotations.
- Keep annotation schemas, placement rules and domain validation in the
  consuming generator.

This module uses the independent `tools/v0.1.1` tag. It does not change the
root module's dependency graph or deploy documentation independently.
