# gosr tools v0.1.0

Provide generator adapters in the separate `github.com/longxi-go/gosr/tools`
module. Requires Go 1.27.0 or later and gosr v0.1.0.

- Parse registered comment markers through controller-tools and expose source
  positions with diagnostics.
- Load Go packages with syntax and type information through x/tools.
- Diagnose missing annotation samples and accept a nil package-load configuration.
- Validate marker prefixes, ignore block comments and order structured package
  diagnostics independently of root order.
- Use golayout v0.1.4 for repository formatting and source-header tooling.

The module supplies adapters for generators. It does not define a shared marker
schema, component scanner or cross-generator ABI.
