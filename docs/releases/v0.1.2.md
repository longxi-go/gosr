# gosr v0.1.2

Extend the environment and IoC contracts with nested placeholder keys,
profile predicates and explicit initialization prerequisites.

- Specify nested-key expansion such as `${${stage}.url:localhost}`, including
  missing-key defaults, escaped placeholders and shared resolution limits.
- Add `ParseProfilePredicate` for a profile name or its negation. Invalid
  predicates return classified errors without including the supplied text.
- Add the optional `EnvironmentAccessor` interface for accessing a context's
  configuration environment without transferring shutdown ownership.
- Add `BeanDefinition.DependsOn`, with validation and detached cloning.
  Prerequisites complete construction and `Init` before the dependent factory
  runs; they do not imply `Start` completion or application readiness.
- Expose `imports.BlankAlias` for generated initialization imports and document
  the contracts in English and Simplified Chinese.

The root module requires Go 1.27.0 or later and uses only the Go standard library.
Container execution, annotation schemas and configuration-source policies remain
the responsibility of implementations. The tools module is released separately.
