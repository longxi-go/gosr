# gosr v0.1.1

Add read-only traversal for immutable environment values.

- Add `Value.Len`, `Value.Elements` and `Value.Members` without copying entire
  collections. List traversal preserves index order; object order is unspecified.
- Support early termination, repeated traversal and concurrent readers. Existing
  `Items` and `Fields` continue to return detached copies.
- Document the access semantics in the English and Simplified Chinese manual,
  and add executable examples, regression tests and early-termination benchmarks.

The root module remains dependent only on the Go standard library. This release
contains no tools module update and does not change environment implementations
or configuration-source policies.

## Validation

- `make check docs-build`
- `make validate-release TAG=v0.1.1`
- Read-only iteration benchmarks for collections of 10 and 100,000 elements
