# gosr v0.1.0

Define portable Go contracts and shared code-generation mechanisms. The root
module depends only on the Go standard library and requires Go 1.27.0 or later.

- Define portable IoC metadata, lookup, lifecycle, scope and error contracts.
- Define independent ordering, synchronous event and environment contracts.
- Provide typed sequential steps and cohesive code-generation mechanisms.
- Report import diagnostics in path order and reject invalid type qualifiers.
- Reject conflicting output paths before staging, preserve updated permissions
  and recheck cancellation before replacement or removal.
- Publish bilingual API semantics, examples and integration guidance.

Generator adapters are provided by the separate `github.com/longxi-go/gosr/tools`
module, released under `tools/vX.Y.Z` tags after its declared root dependency is
published.
